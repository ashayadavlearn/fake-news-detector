# Veritas — Fake News Detector

A full-stack, Python-first fake news detector: Flask backend, SQLite database,
scikit-learn ML pipeline, and a dark "liquid glass" UI rendered with plain
Jinja2 templates, CSS, and vanilla JS (no frontend framework/build step).

## Features

- **Home page** — hero, animated stat counters, pipeline explainer, CTA.
- **Detector page** — paste a headline/article, get **REAL ✅ / FAKE ❌** with
  a confidence score. AJAX-powered (`/api/detect`) with a classic form-POST
  fallback. Includes Detect / Clear / Sample news buttons.
- **History page** — every prediction logged to SQLite, searchable, paginated,
  deletable, exportable to CSV.
- **Admin login + dashboard** — Flask-Login session auth, total predictions,
  real/fake counts, model accuracy, a distribution chart (Chart.js), and a
  model comparison table.
- **ML pipeline** — TF-IDF + 4 candidate classifiers (Logistic Regression,
  Naive Bayes, Random Forest, Passive Aggressive), auto-selects the best one
  by held-out accuracy, saves `model.pkl` + `vectorizer.pkl`.
- **Security** — CSRF protection (Flask-WTF) on every form and the AJAX
  endpoint, parameterized queries via SQLAlchemy (no raw SQL / no SQL
  injection surface), Jinja2 autoescaping (XSS), hashed passwords
  (Werkzeug), secure session cookies, security response headers.

## Quickstart

```bash
pip install -r requirements.txt
python train_model.py     # trains + saves model.pkl / vectorizer.pkl
python app.py              # http://localhost:5000
```

Default admin login (change before deploying!):

- **Username:** `admin`
- **Password:** `Admin@12345`

Set `ADMIN_USERNAME` / `ADMIN_PASSWORD` / `SECRET_KEY` as environment
variables (see `.env.example`) to override these.

## About the dataset

`train_model.py` looks for `dataset/Fake.csv` and `dataset/True.csv`. If they
don't exist, it auto-generates a small **synthetic bootstrap dataset**
(`dataset/generate_sample_dataset.py`) so the whole pipeline runs end-to-end
with zero external downloads — useful for verifying the app works, but it's
templated data and will report unrealistically high accuracy.

**For real accuracy**, replace those two files with the public
["Fake and Real News Dataset"](https://www.kaggle.com/datasets/clmentbisaillon/fake-and-real-news-dataset)
(~12,600 rows each; `True.csv` from Reuters, `Fake.csv` from flagged
unreliable sources). Keep the same column names (`title`, `text`, `subject`,
`date`), then re-run `python train_model.py`.

## How the ML pipeline works

```
raw text
   │
   ▼
utils.clean_text()        lowercase → strip URLs/HTML/punctuation/digits
                           → remove stopwords → lemmatize (NLTK)
   │
   ▼
TfidfVectorizer            max_features=5000, unigrams+bigrams
   │
   ▼
4 candidate models trained on an 80/20 stratified split:
   Logistic Regression · Naive Bayes · Random Forest · Passive Aggressive
   │
   ▼
best model chosen by test-set accuracy → saved as model/model.pkl
vectorizer saved as model/vectorizer.pkl, metrics as model/metadata.pkl
```

`predict.py` loads those artifacts once and reuses them for every request;
confidence comes from `predict_proba` where available, or a sigmoid of the
decision margin for `PassiveAggressiveClassifier` (which has no native
probability output).

## Deployment

### Render / Railway
Both platforms auto-detect the `Procfile`:
```
web: gunicorn app:app --workers 2 --threads 4 --timeout 90 --bind 0.0.0.0:$PORT
```
1. Push this repo to GitHub, create a new Web Service pointing at it.
2. Build command: `pip install -r requirements.txt && python train_model.py`
3. Set environment variables from `.env.example` (`SECRET_KEY`,
   `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `FLASK_ENV=production`).
4. Attach a persistent disk (Render) or volume (Railway) if you want the
   SQLite file and trained model to survive redeploys — otherwise point
   `DATABASE_URL` at a managed Postgres instance for real production use.

### PythonAnywhere
1. Upload the project (or `git clone` it in a Bash console).
2. Create a virtualenv, `pip install -r requirements.txt`, run
   `python train_model.py` once.
3. In the **Web** tab, create a new Flask app pointing at `app.py`'s `app`
   object, set the working directory to the project root, and reload.

## Notes & limitations

- SQLite is fine for a demo/small deployment; swap `DATABASE_URL` for
  Postgres/MySQL for concurrent production traffic.
- The bundled dataset is synthetic — see "About the dataset" above before
  trusting the reported accuracy for anything real.
- This is a demonstration project, not a substitute for professional
  fact-checking or media literacy.
